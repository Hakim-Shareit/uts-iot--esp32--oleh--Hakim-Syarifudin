# UTS Praktikum Internet of Things - ESP32 (Wokwi)

UTS Ganjil TA 2026/2027, Program Studi Informatika UNISDA Lamongan.

| Folder | Soal | Pin |
|---|---|---|
| `soal1_pwm_led_bertingkat/` | Kecerahan LED bertingkat (PWM) + push button dengan debouncing | LED GPIO 16, tombol GPIO 4 |
| `soal2_ldr_adc/` | Pembacaan LDR (ADC 12-bit) dan persen kegelapan tiap 1 detik | LDR AO GPIO 34 |
| `soal3_relay/` | Relay aktif 5 detik, mati 3 detik berulang | Relay IN GPIO 19 |
| `soal4_palang_servo/` | Palang otomatis: servo + sensor ultrasonik HC-SR04 | Servo GPIO 18, Trig GPIO 5, Echo GPIO 17 |
| `soal5_mqtt/` | Publish data cahaya dan subscribe kontrol relay via MQTT | LDR GPIO 34, relay GPIO 19 |

Setiap soal dibuat sebagai project Wokwi terpisah. Salin isi file `.ino` ke `sketch.ino`.
